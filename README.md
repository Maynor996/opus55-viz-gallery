### 怎么用

  1. 打开仓库或在线画廊，按兴趣点进条目（原帖 / Demo / 提示词）。
  2. 复制提示词到 Claude Opus 5.5（Claude Code / App / 任意接入）。
  3. 动效/讲解类建议要求：单 HTML + 时间轴渲染 + ffmpeg 导出；游戏/3D 多轮迭代很正常。

仓库里还单独整理了「附提示词」章节，例如动效开源模板、Transformer 讲解、《大气环流》地理动画等，可直接抄作业。
